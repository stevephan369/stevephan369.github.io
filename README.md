# Dr. Truc T. T. Phan — Academic Website

Responsive bilingual starter website for GitHub Pages. No build tools or dependencies are required.

## Publish
1. Create a GitHub repository (for example `truc-phan`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. GitHub Pages will publish the website at `https://YOUR-USERNAME.github.io/truc-phan/`.

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com`.
- Replace the portrait placeholder with a professional photo.
- Add your actual Google Scholar, ORCID, LinkedIn, and institutional profile URLs.
- Verify every publication's title, authors, journal, year, DOI, and contribution details.
- Add verified project details, student supervision information, and partner institutions.
- Confirm the official English institution/department name and current title.

This draft uses information previously provided by the site owner. It deliberately does not invent metrics, publication details, contact information, or endorsements.
